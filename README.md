# BabySound — Android ML Practice

An Android application built as a **practice project** to explore audio classification and on-device machine learning.

> **Project Status: Practice / Incomplete**
>
> This project is not intended to be presented as a production-ready baby-cry interpretation system.

##  Objective

The goal of this project is to learn how to:

* Capture and process audio on Android
* Extract useful audio features
* Integrate an ML model into an Android application
* Perform inference locally on the device
* Convert model predictions into meaningful categories

##  Tech Stack

* **Kotlin**
* **Android SDK**
* **TensorFlow Lite / On-device ML**
* **Android Studio**
* **Audio Processing**

##  ML Approach

The application explores the pipeline:

```text
Audio Input
    ↓
Audio Preprocessing
    ↓
Feature Extraction
    ↓
ML Model
    ↓
Prediction
    ↓
Meaningful Category
```

##  Current Status

This repository is currently a **learning/practice implementation**.

Some parts of the application and ML pipeline are incomplete and may require further development before the project can be considered production-ready.
